# Nexo Transporte — actualización de interfaz

## Cambios incluidos
- Nueva pantalla principal con acceso a Camiones, Camioneros, Ciudades, Paquetes y Asignaciones.
- Tema visual compartido: encabezados, paleta de colores, campos de formulario, botones y tablas.
- Las ventanas secundarias ahora se pueden cerrar sin finalizar toda la aplicación.
- Se conservan las clases DAO, modelos, operaciones CRUD y la conexión que ya tenía el proyecto.

## Abrir en NetBeans
1. Extrae la carpeta `appTransporte`.
2. En NetBeans, selecciona **File > Open Project** y elige esa carpeta.
3. Revisa la configuración de conexión a MySQL de tu entorno.
4. Ejecuta `umg.UI.AppTransporte` para abrir el panel principal.

La interfaz nueva se aplica al ejecutar la aplicación; el editor visual de NetBeans no necesariamente mostrará el encabezado añadido en tiempo de ejecución.
